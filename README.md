# OLEG DMX · Alpha 0.4

Офлайн-пульт управления светом. Новый интерфейс работает на PySide6/Qt; шоу и настройки остаются локальными.

## Запуск

1. Установите Python 3.10+.
2. В папке приложения создайте окружение и установите зависимости:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

3. Запустите `Start OLEG Alpha.bat` или `.\.venv\Scripts\python.exe main.py`.

## Новый интерфейс

- Разделы «Консоль», «Сцена», «Snapshots», «Патч» и «Связь».
- Перемещаемые и масштабируемые объекты сцены; выделение рамкой и совместное перемещение группы; масштаб колёсиком и кнопками.
- Векторные значки музыкантов и цветные лучи прожекторов, показывающие текущий цвет света.
- В Snapshots одновременно видны сцена LIVE и отдельная сцена предпросмотра; обе используют общую раскладку.
- Выбор прибора щелчком по плану синхронизирует список и фейдеры; менять раскладку можно во вкладке редактора сцены.
- Фейдеры RGBW и яркости, список приборов, настройка базового патча и подключение DMX через COM-порт.
- Три цветовых фейдера RGB, белый и яркость отдельно; сохранённые цветовые пресеты с быстрым применением и удалением правой кнопкой мыши.
- GANG-группы со связанными фейдерами, настройкой каналов и временной изоляцией приборов.
- Создание, переименование, копирование, редактирование уровней каждого прибора, удаление и FIRE snapshots; live-панель показывает номер, переход и состояния «в эфире» / «предпросмотр».
- Список snapshots нумерован и помечает текущий LIVE-cue; выбранный snapshot подписан над предпросмотром. Выбор карточки в консоли синхронизируется со списком; после FIRE можно автоматически выбрать следующий cue.
- Настраиваемый плавный переход для каждого snapshot с остановкой перехода при ручном вмешательстве.
- BLACKOUT, Ctrl+Z / Ctrl+Shift+Z, Ctrl+C / X / V, Ctrl+D, F2 и Delete.
- Открытие и сохранение файлов шоу формата версии 1 с проверкой данных и резервной копией `.bak`.

Интерфейс оформлен в тёмной сценической палитре с отдельным верхним слоем навигации и рабочих действий. Интеграция с ProPresenter и управление playback пока не подключены; интерфейс и модель шоу оставляют для них отдельную область.

## Структура

- `main.py` — запуск Qt-приложения.
- `luma_qt.py` — окна и интерфейс оператора.
- `luma_core.py` — формат шоу, проверка данных и независимый DMX-выход.
- `legacy_tk.py` — прежний интерфейс, оставленный для сверки поведения во время переноса.
